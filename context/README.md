# TOBEE Context
The identity of the Tobee AI lives in the context files. These should either be passed along with the chat, or configured in the AI provider (LM Studio, in my case) before the chat is initiated.

## About Files
- `PROMPT.md` - Descriptions of the duties of the agent, and the response format it must follow.
- `SOUL.md` - The identity of the agent, and its tendencies.
